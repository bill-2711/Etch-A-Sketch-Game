# Sketch Pad

A simple browser-based sketch pad built with **HTML, CSS, and JavaScript**.

The project allows a user to enter a number and dynamically generate a grid of boxes. The boxes respond to mouse interaction, giving the page a simple sketching effect.

This project was built to practice working with the DOM, user input, events, loops, and basic JavaScript timing.

## Features

- Generate a grid based on user input.
- Dynamically create grid elements with JavaScript.
- Hover over grid boxes to change their color.
- Modal interface for entering the grid size.
- Press **Enter** to generate the grid.
- Press **Escape** to close the modal.
- Automatically hide the modal after the grid is created.
- Dark, modern interface.

## How to Use

1. Open the project in your browser.
2. Click **Create a Box**.
3. Enter the desired number.
4. Press **Enter** to generate the grid.
5. Move your mouse over the boxes to interact with them.
6. Press **Escape** whenever you want to close the modal.
